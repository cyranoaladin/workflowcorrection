# Contributing

## Branches

Use agent-suffixed branches when multiple agents are active:

```text
feat/phase-N-slug-codex
feat/phase-N-slug-cascade
feat/phase-N-slug-human
```

Do not force-push shared branches. Use fix-forward commits.

## Main Branch

No direct commits to `main`. Changes go through pull requests with required CI checks and review.

## Pull Requests

Include:

- What
- Why
- How
- Test plan
- Acceptance checklist

Use Conventional Commits for commit messages.
